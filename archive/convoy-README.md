# Tidelink / 接力拖航

Godot 4.7 可玩的连续接船原型。旧版靠泊和叠塔代码备份在 `archive/`。

```sh
godot --path /Users/eric/Documents/repos/ai/t12
```

## 操作

点“启航”，小船会交替从航道两侧漂来。对齐船队末端的光圈时，点击水面或按空格接上。Esc 暂停。

## 这次改了什么

- **上一次的结果成为下一次条件。** 接入时的横向误差写入缆绳关节的固定偏移。下一艘瞄准的是实际船尾；两次同向接偏会累积，目标不会自动复位。
- **船队共同受力。** 新船的横向动量通过双向弹簧链传给前船，海流作用于全队。船越多，队尾越容易晃动；接船时需要追随移动目标。
- **连续操作，没有逐船结算。** 点击后立即生成下一艘，上一艘的转向与下一次瞄准并行。没有五秒收缆等待，没有“下一艘”按钮。
- **可以主动纠偏。** 在可接范围内故意向航道内侧接入，可以抵消之前的偏移；精准接船修复缆绳，三连精准还会收紧旧关节，减轻累积偏移。
- **失误有累积后果。** 落空或漏船损失缆绳强度，并拉扯队尾；擦过航道浮标线或关节受力过大也会损伤。强度耗尽才结束整次航行。
- **航行持续推进。** 航速逐渐提高。队伍达到上限后，前船自动交接给补给船，保留后队的横向偏移与动量，不重置整局。画面最多保留七艘主队船，避免无限缩小。

## 验证

```sh
godot --headless --path . -- --self-test
godot --path . -- --demo --duration=22
godot --path . --write-movie /private/tmp/tidelink.avi --fixed-fps 30 -- --demo --record --duration=22
```

自动检查：偏移继承和叠加、双向动量、零等待下一次输入、三连纠偏、失误后持续进船、32 秒连续正常接船、前船交接不清除队尾偏移、擦线损伤、暂停、失败重开，以及持续同向误差导致实际擦线败局。

演示只调用普通接船动作，不直接设置成绩或船队状态。玩家最高记录与测试、演示隔离。音乐未接入。
